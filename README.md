# SillyGlamourBridge
A Tampermonkey script for SillyToolbox module, used to export glamour set information to json format.

## Supported website
- [Eorzea Collection](https://ffxiv.eorzeacollection.com/)
- [Glamour page of FF14 Rising Stones](https://ff14risingstones.web.sdo.com/pc/index.html#/glamour)
